DiazoDB

About the database

Automated annotation and curation of nitrogenase genes using profile hidden Markov models and conserved residue matching.

Citation

DiazoDB: Interactive Nitrogenase Web Database, Shivji (2026).

doi:10.5281/zenodo.21909831

Source code

DiazoDB is developed in the open. The repository contains the analysis scripts, HMM seeds, web application, and reproducibility files.

View the DiazoDB source code on GitHub

Data provenance

Source data: Genome Taxonomy Database (GTDB) R232.

  • GTDB representative proteins
  • GTDB bacterial taxonomy
  • GTDB archaeal metadata

Manually curated seed files include nifH, nifD, nifK, nifE, nifN, nifB, anfG, vnfG, and anfO.
