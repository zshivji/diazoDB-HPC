# NFixPlanet release 1.0

### NFixPlanet gene database

The NFixPlanet gene database was generated by applying the `nfixplanet annotate` pipeline described below to genomes and contigs from the [proGenomes v3](http://progenomes3.embl.de/) and [SPIRE](https://spire.embl.de/) databases. It contains nucleotide sequences for nif, vnf, and anf genes, together with closely related homologous gene families used during annotation and classification.

### NFixPlanet metagenome database

The NFixPlanet metagenome database contains abundance profiles generated from 9,163 metagenomes that were processed using `nfixplanet profile` as described below. It includes nitrogenase gene abundance tables and diazotroph abundance tables for all 9,163 metagenome samples. Here, an OTU is defined as a unique genome or contig. Taxonomic abundance tables are provided as `OTU_group_summed_by_<rank>.tsv`, where rank abbreviations are d (domain), p (phylum), c (class), o (order), f (family), g (genus), and s (species). Values represent normalized average read depth and have not been transformed to compositional relative abundances.

### NFixPlanet genome database

The NFixPlanet genome database contains genome and contig sequences for all putative diazotrophs identified in this analysis. All genome and contig sequences were obtained from the [proGenomes v3](http://progenomes3.embl.de/) and [SPIRE](https://spire.embl.de/) databases. Due to the large file size, the genome database is distributed separately as `NFixPlanet_r1.0_genome_db.tar`.

### NFixPlanet HMM profiles

This collection contains the HMM profiles generated in this study and used to identify nitrogenase genes and closely related homologs.

### NFixPlanet metadata

This collection contains metadata associated with the data products described above. The metadata include project-derived annotations as well as metadata compiled from [proGenomes v3](http://progenomes3.embl.de/), [SPIRE](https://spire.embl.de/), [METALOG](https://metalog.embl.de/), and [Kim et al. 2026](https://doi.org/10.1016/j.cell.2025.12.051).
- `nfixplanet_gene_info_r1.0.tsv`: Gene-level annotations and classifications.
- `nfixplanet_taxonomy_reference_r1.0.tsv`: Taxonomic assignments for genomes and contigs.
- `nfixplanet_habitatcluster_r1.0.tsv`: Habitat cluster assignments from [Kim et al. 2026](https://doi.org/10.1016/j.cell.2025.12.051).
- `nfixplanet_metalog_r1.0.tsv`: Environmental metadata compiled from [METALOG](https://metalog.embl.de/).

# Workflow
All data were generated using the NFixPlanet v1.0.0 Python package. The annotation and mapping workflows used to generate the database are summarized below. See the accompanying manuscript for a more detailed description of the methodology.
### NFixPlanet annotation pipeline
Pipeline for identifying nitrogen fixation genes and operons in nucleotide sequences.
This workflow:

1. Predicts open reading frames (ORFs) using Prodigal (optional if ORFs are provided)
2. Searches ORFs against curated nitrogen fixation HMM profiles using HMMER
3. Retains the best HMM hit per ORF
4. Filters results to ensure required genes occur on the same contig
5. Performs genomic context validation based on operon structure and gene proximity
6. Resolves ambiguous gene assignments (e.g., nifH vs vnfH) using neighboring genes

Output consists of high-confidence nitrogen fixation gene annotations and operon assignments.

This workflow can be applied to any nucleotide sequence including genome assemblies, metagenome-assembled genomes (MAGs), or individual contigs.

### NFixPlanet mapping pipeline
Pipeline for quantifying diazotroph gene, genome, and taxonomic abundance from short-read metagenomes.
This workflow integrates read mapping, abundance estimation, and taxonomic profiling into a single pipeline.
Steps include:

1. Pre-processing quality control on metagenomic reads
2. Mapping metagenomic reads to a curated diazotroph reference gene database using CoverM
3. Calculating coverage per gene across samples
4. Aggregating gene coverage into genome-level abundance estimates
5. Normalizing genome abundance by gene count per genome
6. Assigning genomes to taxonomy using a reference taxonomy table
7. Aggregating genome abundance into taxonomic abundance profiles
